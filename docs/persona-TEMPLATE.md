## Appendix — what to pull for a persona (delete from the finished doc)

> 📝 The reusable data shopping-list. Ask each source for **modal value + share**, not averages or trends. Scope the source to the persona first (e.g. Domestic + VTAC + School Leaver) so numbers are real, not proxies.

**Tier 1 — could change the story (get first):** main application route · field/course concentration (is there a dominant one?) · study-type split (degree/vocational) · commitment to the institution (e.g. preference position — chosen vs hedged) · location (metro/regional) · **motivation / reason for study**.

**Tier 2 — makes it credible:** age · SES · study load · gender (informs naming/gendering) · school/background · attainment band (e.g. ATAR) · outcome mix (offered/accepted/deferred).

**Tier 3 — where the journey breaks (if cheap):** engagement at key moments · opt-out/unsubscribe points · first known touchpoint.

**From the comms dataset itself:** comms per stage · repetition (same comm, multiple sends) · question↔comm coverage.

**Scoping traps (check before trusting a number):** filter *panels* don't always respect other filters — verify against the report visual · "preferences" ≠ students (dedupe to people for demographics) · a big unfiltered number is usually the whole model · use a broad-but-close cut as a proxy only when the excluded slice is small, and say so.
